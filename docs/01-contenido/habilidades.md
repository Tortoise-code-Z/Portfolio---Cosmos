# Habilidades (constelaciones)

Cada grupo es una constelación en la galaxia. Los `id` los usa la escena para colocar cada estrella
(posiciones en `docs/04-escena/`). El orden dentro del grupo es el orden de lectura en el panel.
Son **4 constelaciones**: la escena reserva sitio para las cuatro.

| Grupo `id` | Título EN | Título ES |
|---|---|---|
| `web` | Web development | Desarrollo web |
| `libraries` | Libraries & frameworks | Librerías y frameworks |
| `tools` | Tools & workflow | Herramientas y flujo de trabajo |
| `ai` | AI-assisted development | Desarrollo con IA |

## `web` · Desarrollo web

## `ai` · Desarrollo con IA

Trabajo diario con IA como parte del flujo de desarrollo (también lo dice la bio en `perfil.md`).

| id | Etiqueta EN | Etiqueta ES |
|---|---|---|
| `ai-pair` | AI pair programming | Programación en pareja con IA |

| `ai-prompting` | Prompt & context engineering | Ingeniería de prompts y contexto |

⚠ Por confirmar: si quieres nombrar herramientas concretas como estrellas (por ejemplo Claude, ChatGPT,
GitHub Copilot u Ollama) en lugar de, o además de, las prácticas. Las prácticas envejecen mejor que los nombres
de producto.

## Regla

No se añaden habilidades que no se usen de verdad. Las de Cosmos (`r3f`, `vitest`, `playwright`) quedan
respaldadas por este mismo proyecto cuando esté construido.
