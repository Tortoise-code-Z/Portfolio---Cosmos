## About

**EN**
1. AstroHub is a dynamic, complete web application built as the final project of the web development module of
   the MasterD Full-Stack program.
2. Inspired by the universe and space exploration, it combines front end, back end and database.
3. It supports user registration, profile management, news administration and astronomy appointments, all built
   with HTML, CSS, JavaScript, PHP and MySQL.
4. It was tested and run locally with XAMPP, covering both the public site and the internal user and admin
   panels.

**ES**
1. AstroHub es una aplicación web dinámica y completa, desarrollada como proyecto final del módulo de desarrollo
   web del curso Fullstack de MasterD.
2. Inspirada en el universo y la exploración espacial, combina frontend, backend y base de datos.
3. Permite registro de usuarios, gestión de perfiles, administración de noticias y control de citas
   astronómicas, todo con HTML, CSS, JavaScript, PHP y MySQL.
4. Se probó y ejecutó en local con XAMPP, integrando la parte pública y los paneles internos de usuario y
   administrador.

## Process

**EN**
1. AstroHub covered the whole stack. The interface was built with HTML5, CSS3 and JavaScript, while server logic
   and data handling ran on PHP and MySQL.
2. An authentication and role system (visitor, user and admin) controls access to each section, with separate
   panels to manage news, appointments and profiles.
3. The database was created and imported with phpMyAdmin and run locally on XAMPP for a realistic test
   environment.

**ES**
1. AstroHub abarcó todo el stack. La interfaz se hizo con HTML5, CSS3 y JavaScript, y la lógica de servidor y
   los datos, con PHP y MySQL.
2. Un sistema de autenticación y roles (visitante, usuario y administrador) controla el acceso a cada sección,
   con paneles diferenciados para gestionar noticias, citas y perfiles.
3. La base de datos se creó e importó con phpMyAdmin y se ejecutó en local con XAMPP, para un entorno de pruebas
   realista.
