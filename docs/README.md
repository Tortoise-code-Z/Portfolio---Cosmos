## Orden de prioridad si dos documentos chocan

1. Decisiones registradas en `DECISIONS.md` (cuando exista).
2. `00-vision/brief.md` (principios).
3. El documento específico del tema.
4. El prototipo (solo como referencia; nunca manda sobre la especificación).
